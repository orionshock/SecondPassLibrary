# Project Name and Branding Policy

The names **Second Pass Library** and **Second Pass Reader** identify the
official projects and releases maintained by the original project owner. The
project owner determines what may be presented as an official release under
those names.

The Apache License 2.0 permits forking, modifying, redistributing, and building
on the software. It does not grant a general right to use the project names or
distinctive branding in a way that suggests an unofficial work is official.

## Forks and modified distributions

A materially modified fork or distribution must use a meaningfully distinct
product or project name. It must not present itself simply as **Second Pass
Library** or **Second Pass Reader** when it is not an official release.

A distinguishing addition or change is sufficient. Examples of the intended
style include:

- Acme Second Pass Library
- Second Pass Library Community Edition
- Second Pass Reader for ExampleOS

These examples are illustrative, not required naming formats. The practical
rule is to avoid confusion with the official project.

Modified distributions should preserve notices required by Apache-2.0 and
clearly acknowledge their origin when appropriate. Straightforward wording
such as “Based on Second Pass Library” or “Derived from Second Pass Reader” is
welcome; deceptive or excessive attribution is not required.

## Descriptive use and official status

The project names may be used descriptively to explain compatibility, origin,
or derivation. Forks, packages, hosted services, and derivative releases must
not imply endorsement, sponsorship, or official status without explicit
authorization from the project owner.

An unmodified official release may be redistributed under its original name
when it is presented accurately as the official upstream software rather than
as an independently maintained fork.

## Branding assets

Distinctive project branding in this repository, including logos, icons, and
badges, is governed by this name and branding policy. The Apache-2.0 software
license does not by itself grant permission to use project names or branding
beyond reasonable descriptive, attribution, and unmodified-redistribution use
described above.
